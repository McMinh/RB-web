# ⚔️ Riftbound Collection Manager

Trang web quản lý bộ sưu tập thẻ Riftbound TCG.

## 🌐 Demo

https://mcminh.github.io/RB-web/

## ✨ Tính năng

- 📚 Quản lý bộ sưu tập (thêm/xóa/sửa số lượng)
- 🔍 Tìm kiếm thẻ theo tên, domain, rarity
- 📥 Import từ CSV (Excel)
- 📤 Export ra JSON/CSV
- 📊 Thống kê theo domain, rarity, type
- 💾 Lưu trữ cục bộ (LocalStorage)

## 🛠️ Công nghệ

- HTML/CSS/JavaScript thuần
- GitHub Pages (hosting)

## 📖 Hướng dẫn sử dụng

1. Mở trang web
2. Vào tab **Import** → chọn file CSV (hoặc thêm thủ công)
3. Xem bộ sưu tập ở tab **Bộ sưu tập**
4. Dữ liệu tự động lưu trong trình duyệt
